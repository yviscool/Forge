# Forge Agent Guide

Run `go test ./...` and `go build ./...` before reporting completion. HTTP API is versioned under `/api/v1` (no backwards-compat guarantee pre-launch; cut boldly). Domain rules belong in `internal/domain` (pure, testable); use-cases in `internal/app` (manual DI via `NewService`); HTTP transport in `internal/transport/http`; persistence behind `internal/ports.Store` (`memory` now, `sqlite` next). Web SPA source lives in `frontend/`, built output embeds from `internal/web/dist` — never hand-edit `dist`. Do not execute submitted code directly on the host: the service records submissions and judge results only, and a sandboxed judge worker is a planned module.
