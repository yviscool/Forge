# Forge Agent Guide

Run `go test ./...` and `go build ./...` before reporting completion. HTTP API is versioned under `/api/v1` (no backwards-compat guarantee pre-launch; cut boldly). Domain rules belong in `internal/domain` (pure, testable); use-cases in `internal/app` (manual DI via `NewService`); HTTP transport in `internal/transport/http`; persistence behind `internal/ports.Store` (`memory` now, `sqlite` next). Web SPA source lives in `frontend/`, built output embeds from `internal/web/dist` — never hand-edit `dist`. Submitted code is never executed outside `internal/judge`: auto judging is opt-in (`FORGE_AUTOJUDGE` + `FORGE_ALLOW_UNSAFE_LOCAL_JUDGE`), sandboxed per platform (Windows LowBox+ACL+Job, Linux bwrap/prlimit/cgroup v2, macOS ulimit), and every probe degrades safely to weaker walls instead of failing runs.
